# Zalo Web Chat

Build target from the attached prompt:

- Node.js ES Modules.
- Express, Socket.IO, SQLite, zca-js.
- QR login with saved credentials in `data/credentials.json`.
- Message persistence in `data/zalo.db`.
- Two-column dark chat UI with avatars, timestamps, date dividers, and realtime updates.

Run:

```bash
npm install
npm start
```

Open `http://127.0.0.1:3790`.
